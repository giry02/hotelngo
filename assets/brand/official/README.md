# HotelnGo 공식 로고 자산

웹 워드마크는 05번 Go Capsule 시안의 공식 SVG를 이미지로 사용한다. 원형 디자인 소스는 `../exploration-20260801/hotelngo-logo-05-go-capsule.svg`에 보관한다.

| 파일 | 용도 | 배경 |
|---|---|---|
| `hotelngo-logo-go-capsule.svg` | 웹 헤더·푸터·로그인·운영 화면 워드마크, 420 × 100 viewBox | 투명 |
| `hotelngo-logo-go-capsule-on-dark.svg` | 어두운 로그인 비주얼·운영 사이드바용 워드마크 | 투명 |
| `hotelngo-logo-primary.png` | 이전 래스터 내보내기, 호환 보관 | 투명 |
| `hotelngo-symbol-primary.png` | 파비콘·앱 아이콘·작은 배너 | 투명 |
| `hotelngo-symbol-primary.svg` | 확대 출력용 단독 지도 마커 | 투명 |

## 사용 우선순위

- 홈페이지와 하위 페이지는 `hotelngo-logo-go-capsule.svg`를 데스크톱 기준 144px로 표시한다.
- 비교 원본은 `../exploration-20260801/hotelngo-logo-comparison-v14.html`의 05번이다.
- `hotelngo-logo-go-capsule.svg`는 `<img>`로 사용하고 HTML 텍스트나 인라인 SVG로 재조립하지 않는다.
- 로고 비율, 글자 간격, `n` 색상, 지도 마커와 내부 화살표를 개별 수정하지 않는다.
- 배경은 투명이다. 밝은 단색 배경에서 사용하며 사진이나 복잡한 배경에는 흰색 보호 영역을 둔다.
