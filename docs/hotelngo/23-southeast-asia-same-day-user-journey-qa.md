# 동남아 당일 출발 사용자 여정 QA

- 점검일: 2026-07-24
- 기준 시나리오: “오늘 동남아로 혼자 3박 4일 여행을 가고 싶다. 바다와 맛집을 즐기되 일정은 너무 빡빡하지 않았으면 좋겠다.”
- 점검 관점: 여행지를 정하지 못한 일반 고객이 탐색부터 예약 확인까지 혼자 완료할 수 있는가
- 실행 환경: HotelNGo 정적 웹 + JSON Mock + 브라우저 저장소

## 1. 최종 판정

현재 프로토타입은 다음 범위까지 실제 화면 흐름으로 실행된다.

1. 메인 통합 검색에서 막연한 동남아 추천 요청을 AI 여행으로 전달
2. 발리·다낭·방콕 후보를 이미지와 추천 이유로 비교
3. 다낭 선택 후 3박 4일 일정 생성
4. 항공편, 호텔, 현지 장소 후보 탐색
5. 현지 상품 선택, 장바구니, 이용자 입력, 예약 검토, Mock 결제
6. 예약번호 발급과 공급자 확인 대기 상태 조회

그러나 “오늘 실제 출발 가능한 여행의 확정 예약”은 아직 불가능하다. 항공 발권, 입국 요건, 호텔 PMS 재고, 현지 업체 슬롯, 결제대행사와 연결되지 않았기 때문이다. 현재 결과는 사용자 흐름과 데이터 계약을 검증하는 프로토타입이며 실시간 판매 결과가 아니다.

## 2. 실행한 사용자 여정

| 단계 | 사용자 행동 | 확인 결과 |
|---|---|---|
| 1 | 메인에서 “오늘 동남아 추천” 검색 | 호텔 검색으로 오인하지 않고 AI 여행 입력으로 이동 |
| 2 | “오늘 동남아로 혼자 3박 4일…” 입력 | 발리·다낭·방콕 3개 후보와 추천 이유 표시 |
| 3 | 다낭 선택 | 휴식 중심 4일 일정 생성 |
| 4 | 항공편 보기 | 인천→다낭, 오늘 출발일과 귀국일이 반영된 Mock 항공편 표시 |
| 5 | 호텔 보기 | 다낭과 2026-07-24~2026-07-27 조건이 검색 결과와 상세 링크에 유지 |
| 6 | 현지 장소 보기 | 다낭 업체만 필터링되어 표시 |
| 7 | 차량 상품 선택 | 상품명·이미지·32,000원 금액이 장바구니에 저장 |
| 8 | 이용자 정보 입력 | KIM MINJI와 이메일이 예약 검토 화면에 유지 |
| 9 | Mock 결제 | `PENDING_SUPPLIER` 상태의 로컬 예약번호 발급 |
| 10 | 예약 상세 확인 | 선택 상품·금액·이용자·예약 상태가 같은 데이터로 표시 |

## 3. 발견 후 수정한 문제

### P0 — 사용자 여정 단절

- 동남아 요청에도 교토 일정이 생성되던 문제를 수정했다.
- 목적지가 다낭인데 파리 항공편이 나오던 정적 항공 화면을 목적지별 JSON 렌더링으로 교체했다.
- 호텔 검색 날짜가 URL과 무관하게 8월로 표시되던 문제를 수정했다.
- 현지 장소가 목적지와 무관하게 다낭·방콕·교토를 섞어 보여주던 문제를 수정했다.
- 장바구니에서 선택하지 않은 호텔과 방콕 체험이 자동으로 섞이던 문제를 제거했다.
- 이용자 입력 이후 예약 검토·결제 화면이 하얏트 호텔과 559,200원으로 바뀌던 문제를 수정했다.
- 생성된 차량 예약 상세가 다시 호텔 예약 정보로 표시되던 문제를 수정했다.

### P1 — 화면과 상호작용

- 랜드마크 대안 목록이 MutationObserver로 반복 생성되던 문제를 수정했다.
- 랜드마크 대안을 요약 카드, 이미지·설명 상세 팝업, 일정 담기 순서로 재구성했다.
- 동남아 후보를 한 번에 선택하도록 강요하지 않고 이미지·추천 이유·적합한 여행 성향을 먼저 보여준다.
- AI 일정 결과에 항공·호텔·현지 장소의 확인 순서를 추가했다.
- 당일 호텔 조회에는 PMS·공급자 API 재확인이 필요하다는 경고를 명시했다.
- 예약 검토와 결제의 반복 렌더링으로 브라우저 탭이 멈추던 문제를 멱등 렌더링으로 수정했다.
- 공통 스크립트가 본문 대신 상단 단계 표시 영역을 선택하던 DOM 선택자 오류를 수정했다.

## 5. 사용자 관점에서 추가로 필요한 안내

- “오늘 출발” 요청을 받으면 먼저 현재 시각, 출발 공항, 여권 유효기간, 비자·입국 조건을 확인해야 한다.
- 실시간 공급 API가 없는 결과에는 “예약 가능” 대신 “후보” 또는 “재확인 필요”를 사용해야 한다.
- 항공 도착 시각보다 이른 호텔 체크인이나 현지 예약은 자동으로 충돌 경고를 내야 한다.
- 현지 상품은 대표 이미지, 소요 시간, 포함·불포함 사항, 취소 규정, 이동 거리, 언어, 최소 인원을 선택 전에 보여줘야 한다.
- 일정 복사 또는 AI 재생성 후에도 사용자가 직접 선택한 상품은 잠기도록 해야 한다.
- 공급자가 거절하면 동일 시간대의 대체 상품을 제안하고, 사용자가 승인하기 전에는 금액을 다시 확정하지 않아야 한다.

## 6. 자동 회귀 점검

- JavaScript 구문 검사: 통과
- JSON 파싱 검사: 통과
- HTML 페이지 수: 192
- 내부 링크 검사: 522개, 누락 파일 0개
- 해시 앵커 검사: 깨진 앵커 0개
- `javascript:void(0)` 및 `href="#"` 임시 링크: 0개
- 버튼 분류 검사: 178개, 미분류 0개

자동 검사는 링크 존재 여부와 기본 분류를 보장한다. 실제 공급자 예약, 결제 승인, PMS 재고 정합성은 외부 API가 준비된 뒤 별도의 통합·계약·대사 테스트가 필요하다.
