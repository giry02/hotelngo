# HotelnGo 인터랙션·레이아웃 품질 기준

검토일: 2026-07-25

## 1. 적용 원칙

- 한 조작군에 배치된 입력창, 선택기, 시간 입력, 실행 버튼은 같은 높이를 사용한다.
- 주요 저장·다음 단계 버튼은 `44px`, 카드 내부의 조밀한 조작군은 `38px`, 보조 필터 칩은 `32px` 이상을 기본값으로 한다.
- 텍스트만으로 기능 구분이 느린 `삭제 / 다시 채우기 / 저장 / 추가`에는 의미가 분명한 선형 아이콘을 함께 사용한다.
- 아이콘은 장식으로 처리하고 버튼의 실제 이름은 텍스트와 접근성 이름으로 유지한다.
- 드롭다운은 브라우저 기본 옵션 창에 의존하지 않는다. 공통 `ui-select`를 사용하며 화면 경계와 스크롤 컨테이너에 잘리지 않아야 한다.
- 좁은 카드 안에서 한 줄 배치가 정보를 가리면 억지로 축소하지 않고 조작군을 카드 전체 폭의 다음 행으로 내린다.
- 목록을 내부 스크롤에 숨길 때는 사용자가 스크롤 영역임을 바로 알 수 있어야 한다. 그렇지 않으면 페이지 흐름으로 모두 노출한다.

## 2. 공통 선택기

- 원본 `select`는 폼 값과 변경 이벤트를 유지한다.
- 표시 UI는 `button + listbox`로 구성하고 키보드 방향키, Enter, Space, Escape를 지원한다.
- 메뉴는 `body` 포털의 고정 레이어로 열어 카드 `overflow`에 잘리지 않게 한다.
- 메뉴 최소 폭은 `140px`이며 화면 좌우 10px 안쪽에 배치한다.
- 아래 공간이 부족하면 위로 열고, 스크롤 또는 리사이즈가 발생하면 닫는다.

## 3. 여행 일정 편집기

- 여행 기본값 → 날짜별 일정 → 추가 카탈로그의 3단계를 화면에서 명확히 구분한다.
- 카테고리 필터에는 숙소, 랜드마크, 식사, 골프, 스파, 투어, 이동 아이콘을 함께 표시한다.
- 상품 카드의 일자·시간·추가 조작군은 이미지와 설명 아래 전체 폭을 사용한다.
- 일정 카드의 일자 이동 선택기와 삭제 버튼은 동일한 `36px` 높이를 사용한다.
- 하단의 `일정 비우기 / 추천 일정 다시 채우기 / 이 일정 저장`은 `44px` 높이와 각각 삭제·새로고침·저장 아이콘을 사용한다.

## 4. 회귀 점검 기준

브라우저 렌더링 후 아래 항목을 자동 점검한다.

- 문서 가로 오버플로
- 깨진 이미지
- 공통 UI가 적용되지 않은 단일 선택기
- 버튼·선택기·입력창의 텍스트 잘림
- 접근성 이름이 없는 버튼
- 내용이 없는 주 콘텐츠 영역

2026-07-25 기준 루트의 HTML 193개를 `1280 × 720` 화면에서 검사했으며 위 항목의 잔여 오류는 발견되지 않았다. 여행 일정 편집기는 드롭다운 선택, 일정 추가, 저장, 비우기, 추천 일정 복원을 별도로 조작 확인했다.
