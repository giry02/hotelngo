# HotelnGo 독립 모바일·하이브리드 구현 보고서

## 결과

- PC 화면과 분리된 `/mobile/` 앱을 구축했다.
- Capacitor Android·iOS 프로젝트를 생성하고 모바일 웹 자산을 동기화했다.
- PWA manifest와 Service Worker를 추가해 설치형 모바일 웹과 기본 오프라인 앱 셸을 제공한다.
- Share, Haptics, Geolocation을 웹·네이티브 공통 브리지로 연결했다.

## 사용자 검증 시나리오

1. 홈에서 다른 여행자의 다낭 여행기를 발견한다.
2. 비로그인 상태에서 `내 여행에 담기`를 누르면 로그인 화면으로 이동한다.
3. 로그인하면 원래 선택했던 여행기가 자동으로 내 여행에 복사된다.
4. 여행 카드에 담긴 랜드마크·숙소·식사를 확인한다.
5. `초안 만들기`로 충돌 없는 4박 5일 일정을 생성한다.
6. DAY 탭을 바꾸면 지도와 시간표가 함께 변경된다.
7. 일정 항목을 누르면 가능한 시간과 체류시간을 바텀시트에서 수정한다.
8. 내 여행에서 커뮤니티 원본과 분리된 수정 가능한 일정을 확인한다.

## 점검 결과

- 390×844 모바일 뷰포트에서 문서 가로 넘침 없음
- 모바일 하단 탭 5개 고정
- 표시된 주요 터치 요소 중 40px 미만 없음
- 여행기 상세 댓글, 스크랩, 공유, 내 여행 복사 경계 확인
- 여행 카드 4개에서 5일 일정 초안 생성 확인
- 날짜별 지도와 3개 일정 항목 전환 확인
- Android Capacitor 8.5.0 동기화 정상
- iOS 프로젝트 생성 및 플러그인 동기화 정상. Windows 환경이므로 Xcode 빌드 검증은 제외
